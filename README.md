# Everson Dias — @eajdias

Construo ferramentas de desenvolvimento e sistemas de atendimento omnichannel em produção.

## Em desenvolvimento

- **envctl** — CLI em Go que padroniza o ambiente de trabalho e transforma VPS em agentes autônomos. ([repo](https://github.com/eajdias/envctl))
- **zscan-omnichannel** — plataforma de atendimento multi-canal com BSC, auditoria e importação MessageBird (privado, em evolução para multi-empresa).
- **zscan_mcp** — servidor MCP do ecossistema Zscan (privado).
